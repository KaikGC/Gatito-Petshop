# 📊 Dashboard de Análise - Gatito (Power BI)

Este é o meu primeiro projeto prático de Business Intelligence, desenvolvido como parte do curso **Power BI Desktop: Construindo meu primeiro dashboard** da [Alura](https://www.alura.com.br/).

## 🎯 Sobre o Projeto

O objetivo deste dashboard é analisar os dados da **Gatito PetShop** para extrair insights valiosos que auxiliem na tomada de decisão do negócio. O painel apresenta indicadores cruciais de forma clara e interativa.

## 🛠️ O que foi feito

* **ETL (Extração, Transformação e Carga):** Limpeza e preparação da base de dados utilizando o Power Query.
* **Modelagem de Dados:** Estruturação das tabelas e criação de relacionamentos para sustentar o modelo.
* **Cálculos com DAX:** Criação de medidas e colunas calculadas para extrair métricas precisas.
* **Data Visualization:** Construção de gráficos interativos e painéis dinâmicos focados na experiência do usuário.

## 💻 Tecnologias Utilizadas

* Power BI Desktop
* Power Query
* Linguagem DAX

## 💡 Aprendizados

Este projeto consolidou meu entendimento do ciclo completo de análise de dados: desde o recebimento de uma base bruta até a entrega de um relatório funcional e visualmente agradável, pronto para responder perguntas de negócio.
